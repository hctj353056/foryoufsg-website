## 写一条词条

在 `wiki-src/内容/<分组>/` 下新建 `.md`：

```markdown
---
标题: 模态逻辑
别名: Modal Logic, 必然算子
标签: 逻辑学, 哲学
---

正文里直接写 [[形式系统]]，或 [[形式系统|换个显示名]]。
```

`标题` 是唯一必填项，缺省时取文件名。`别名` 参与检索加权，`标签` 同时作为分类线索。

## 双链与红链

`[[词条名]]` 在构建时解析为相对路径，**改文件夹、改文件名都不会断链**。

指向尚不存在的词条会渲染成红色虚线——它就是待办清单，首页统计里的「待建」数量即来自这里。写在行内代码里的 `[[示例]]` 不计入。

构建同时统计反向链接，显示在词条页底部。

## 构建

```bash
python3 wiki-src/构建.py
```

产物写入 `_site/`（已在 `.gitignore` 中）。**只改 `wiki-src/`，不要手改 `_site/`**，每次构建都会清空重建。

## 部署

推送 `main` 即自动部署：

```
push → Actions: checkout → python3 wiki-src/构建.py → upload _site → deploy
```

⚠️ 仓库的 Pages 构建来源必须是 **GitHub Actions**（`build_type: workflow`），不能是「从分支部署」——否则 `_site/` 不在 git 里，页面会是 404。

## 版本

当前 `v0.0.3`。版本号在 `wiki-src/构建.py` 顶部：

```python
版本 = "0.0.3"
```

构建时注入三处：每个页面的 `<meta name="version">`、顶栏徽章、页脚。改一处即全站同步。

## 检索规则

| 输入 | 行为 |
|------|------|
| `形式` | 子串匹配，加权排序：标题 > 别名 > 标签 > 摘要 > 正文 |
| `形式 系统` | 空格分词，AND 语义 |
| `/证明.*验证/` | 正则模式，非法表达式会被捕获并提示 |

索引内嵌在首页，因此 `file://` 直接打开也能检索，不需要起服务器。
